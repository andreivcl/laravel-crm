# Trend notes (fed to the idea generator)

Update this file whenever you spot something new. `npm run ideas` passes it to
Claude as context, so concrete observations beat generic ones.

Last reviewed: 2026-11-24. Sources are mostly agency/vendor roundups – treat as
directional, then confirm with your own analytics.

## Visual styles gaining ground
- **Handcrafted / imperfect textures** – grain, painterly 3D, collage. Polished
  "AI-smooth" renders are now common, so texture signals human craft.
  (Videobolt, Renderforest, GarageFarm 2026 roundups)
- **Stylised / NPR 3D** (Spider-Verse lineage): toon bands, halftone, ink lines.
- **Hybrid 2D + 3D**: flat kinetic type over real 3D.
- **Kinetic typography** everywhere – mixed serif-italic + heavy sans pairs.
- **Hypnotic seamless loops** – Shorts/Reels count replays; loops lift watch time.
- **Glass / chrome / iridescent materials** – "liquid glass" product-shot look.
- Grassroots TikTok 3D is humour-driven character animation (Blender memes) –
  mascots with personality outperform abstract shapes on comments/shares.

## Format rules of thumb
- Hook readable on frame 0 (no fade-in). First 3 s decide distribution
  (Instagram exposes `reels_skip_rate` = skips in first 3 s).
- 7–15 s for loops; 20–45 s for how-to.
- Keep text out of the bottom ~480 px and right ~140 px (platform UI).
- Add trending audio **natively in each app** (licensing + reach); render silent
  or with your own licensed track.
